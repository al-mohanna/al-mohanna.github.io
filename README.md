# تلاوات الشيخ د. خالد المهنا

مكتبة ذكية لتلاوات وخطب فضيلة الشيخ د. خالد المهنا، إمام وخطيب المسجد النبوي.

- البيانات تُجلب تلقائياً كل ساعة من قناة يوتيوب عبر GitHub Actions (`scripts/fetch_youtube.py`) وتُحفظ في `data.json`.
- التصنيف (الصلاة، التاريخ الهجري، السور) يتم آلياً من عناوين المقاطع (`scripts/parse_lib.py`).
- الموقع صفحة واحدة (`index.html`) منشورة على GitHub Pages، وتعمل كتطبيق PWA.

يحتاج المستودع إلى سرّ باسم `YOUTUBE_API_KEY` في إعدادات Actions.
